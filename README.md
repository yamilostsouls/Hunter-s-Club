# Hunters Club

Hunters Club es una aplicación Android diseñada para consultar datos sobre los monstruos y compartir sets personalizados del universo de Monster Hunter World.  
Incluye una interfaz intuitiva y herramientas para crear y gestionar builds personalizadas.

---

## Características principales

- Consulta completa de:
    - Armaduras
    - Armas
    - Joyas
    - Ciguas
    - Monstruos
- Sistema de creación de sets con cálculo automático de habilidades
- Búsqueda rápida y filtrado avanzado
- Interfaz ligera y optimizada para móviles
- Compartir sets en tiempo real
- Sistema de registro
